01 — Intention

Une page pour décider, expliquer, vendre sans bluffer

Destinée aux décideurs, intégrateurs et équipes ops : inventaire technique réel, règles actionnables avec exemples quotidiens, et positionnement concurrentiel où CitéVision est meilleure ou à niveau — sans nier les forces Genetec (échelle enterprise, ACS) ni la largeur IoT des suites Smart City.

Preuve avant « validé »

Alerte finale seulement si le package preuve est complet — sinon missing explicite.

Zones jamais hardcodées

Polygones et lignes vivent dans l’éditeur / la DB, pas dans des scripts de secours.

GPU d’abord

CUDA/ONNX prioritaires ; le CPU reste dernier recours, exposé dans /health.

Catalogue véridique

Chaque option UI correspond à un événement réel, avec badge real / partial / beta.
